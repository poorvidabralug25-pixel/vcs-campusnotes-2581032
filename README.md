# CampusNotes

CampusNotes is a student-focused note management application designed to help students organize their academic notes efficiently. Built with HTML, CSS, and JavaScript as part of the Version Control System (CSE25303) coursework at IILM University.

## Features

- Create, read, edit, and delete academic notes.
- Organize notes by subject (Computer Science, Mathematics, Physics, English, Other).
- Search notes by title or content.
- Filter notes by subject.
- Data persists in the browser (localStorage) — no backend required.
- Responsive, clean UI.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Add, search, filter, edit, or delete notes directly in the browser.

No installation or build step is required.
