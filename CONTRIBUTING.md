# Contributing to CampusNotes

Welcome! Here's how you can contribute to this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-change`.
3. Make your changes and commit them using Conventional Commits
   (e.g. `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`).
4. Push your branch: `git push -u origin feature/your-change`.
5. Open a pull request with a clear description.

## Code style

- Keep HTML, CSS, and JavaScript clean and well-indented.
- Write descriptive commit messages.
- Test the app in a browser after making changes.
